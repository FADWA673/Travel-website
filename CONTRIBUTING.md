# Guide de Contribution - PFA Safariyat

Merci de votre intérêt pour contribuer à PFA Safariyat ! 

## Comment contribuer

### 1. Fork le projet
- Cliquez sur "Fork" en haut à droite de la page GitHub

### 2. Clonez votre fork
\`\`\`bash
git clonehttps://github.com/hmirinsalma/travel-website.git
cd PFA
\`\`\`

### 3. Créez une branche
\`\`\`bash
git checkout -b feature/nouvelle-fonctionnalite
\`\`\`

### 4. Faites vos modifications
- Suivez les standards de code Python (PEP 8)
- Ajoutez des tests si nécessaire
- Mettez à jour la documentation

### 5. Testez vos modifications
\`\`\`bash
python manage.py test
\`\`\`

### 6. Commitez vos changements
\`\`\`bash
git add .
git commit -m "Ajout: description de votre fonctionnalité"
\`\`\`

### 7. Poussez vers votre fork
\`\`\`bash
git push origin feature/nouvelle-fonctionnalite
\`\`\`

### 8. Créez une Pull Request
- Allez sur GitHub et cliquez sur "New Pull Request"
- Décrivez vos changements en détail

## Standards de code

- Utilisez des noms de variables explicites
- Commentez le code complexe
- Respectez PEP 8
- Écrivez des docstrings pour les fonctions

## Types de contributions acceptées

- 🐛 Corrections de bugs
- ✨ Nouvelles fonctionnalités
- 📚 Amélioration de la documentation
- 🎨 Améliorations de l'interface utilisateur
- ⚡ Optimisations de performance
